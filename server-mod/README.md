# 1억 기부 서버 코어

현재 개발 버전: **0.2.11**. 이전 버전 JAR과 동시에 설치하지 마세요. 서버와 모든 클라이언트에서 0.2.11로 교체합니다. 설치 절차: `release/update-0.2.11/설치와_테스트.md`.

Minecraft 1.12.2 / Forge 14.23.5.2864 전용 모드입니다. 서버와 모든 클라이언트의 `mods` 폴더에 동일한 JAR을 설치해야 합니다.

## 제공 기능

- 첫 접속 0·0 스폰(운영자 변경 가능), 채팅형 튜토리얼과 1회 완료 보상
- Shift+F 상자형 거점 이동 GUI(아이콘 클릭·마우스오버 설명), 이동 대기·움직임 취소·쿨다운·안전 위치 탐색
- 서버 자체 경제와 `/기부`, `/기부현황`
- 개인 기부 칭호, 채팅 접두사, 1억 달성 방송과 불꽃놀이
- NPC별 상품 등록 상점: 아이템 아이콘·상점명 표시, 1·10·64개 구매/판매
- 판매가 30분마다 무작위 ±10% 변동, 최저가 보장, 5회 연속 하락 뒤 상승 확정
- 좌측 HUD에 잔액·개인 기부·서버 기부 표시
- 월드 `WorldSavedData` 기반 재시작 영구 저장
- `/송금`으로 접속 중인 플레이어 간 서버 화폐 이동
- 첫 청크부터 `[영지 구매권]` 1장 필수, 인접 청크 확장, 소유자/추가 유저만 블록·상호작용 가능
- 영지 경계 파티클·입장 타이틀, 플레이어형 상점 NPC 스킨, 상점가 보호, 스킨 랜덤박스

## 명령어

- `/기부 <금액>` (`/donate`)
- `/기부현황` (`/donationstatus`)
- `/홈설정`
- `/거점이동`
- `/판매상점` (NPC 상점 이용 안내)
- `/튜토리얼완료`
- `/튜토리얼` — 현재 안내 재표시, `/튜토리얼 다음`, `/튜토리얼 이전`, `/튜토리얼 다시`
- `/송금 <접속 중인 닉네임> <금액>` (`/pay`)
- `/영지설정` — 구매권 1장을 사용해 현재 청크 등록
- `/영지설정 해제` — 현재 청크의 내 영지 해제. 구매권 환급 없음
- `/영지설정 정보` — 현재 청크와 내 보유 수 확인
- `/영지설정 표시` — 주변 내 영지의 바깥 경계를 8초간 표시
- `/영지설정 유저추가 <접속 중인 닉네임>` / `/영지설정 유저삭제 <접속 중인 닉네임 또는 UUID>` / `/영지설정 유저목록`
- OP: `/경제관리 거래소설정`
- OP: `/경제관리 돈추가 <플레이어> <금액>`
- OP: `/경제관리 돈설정 <플레이어> <금액>`
- OP: `/상점관리 생성 <NPC 이름>` — 현재 위치에 상점 NPC 생성, ID 출력
- OP: `/상점관리 목록` / `/상점관리 상품 <상점ID>`
- OP: `/상점관리 등록 <상점ID> <구매|판매|둘다> <구매가> <판매가> <최저판매가>` — 주 손 아이템 1개를 상품으로 등록/수정
- OP: `/상점관리 삭제상품 <상점ID> <상품번호>` / `/상점관리 삭제 <상점ID>`
- OP: `/상점관리 구매권등록 <상점ID> <구매가격>` — 구매 전용 `[영지 구매권]`을 해당 NPC 상점에 등록/가격 수정
- OP: `/상점관리 위치설정` — 현재 위치를 거점 이동 메뉴의 상점가 목적지로 지정
- OP: `/상점관리 스킨 <상점ID> <Minecraft닉네임>` — NPC에 플레이어 스킨 적용
- OP: `/상점관리 시세` / `/상점관리 시세갱신` — 남은 시간 확인·즉시 테스트 갱신
- OP: `/유저접속장소설정 [현재|기본|정보]` — 신규 접속 위치 관리
- OP: `/상점가설정 <반경>|정보|해제` — 상점가 몬스터·폭발·블록 변경 보호
- OP: `/스킨박스관리 생성 <이름>` / `보상추가 <ID> <가중치>` / `보상목록 <ID>` / `보상삭제 <ID> <번호>` / `받기 <ID>`
- OP: `/영지관리 최대 <1인 최대 청크 수>` / `/영지관리 현황`

NPC를 우클릭하면 상점이 열립니다. 구매가는 고정이며 판매가만 30분마다 현재가 기준 10% 상승 또는 하락합니다(1원 단위 반올림, 최소 1원 변화). 5회 연속 하락한 다음 회차는 반드시 상승합니다. 최저가에 도달한 경우에도 다음 회차는 상승합니다. 가격과 연속 하락 횟수는 월드 데이터에 저장되며, 서버를 껐다 켠 사이에는 지난 회차 수만큼 소급 변동하지 않고 다음 기동 시 한 번만 갱신합니다. 거래 시 NPC로부터 6블록 이내여야 하고, 서버가 가격·잔액·인벤토리를 재검증합니다.

예: 사과를 양방향 거래로 등록하려면 사과를 주 손에 들고 `/상점관리 등록 1 둘다 200 100 50`을 입력합니다. 판매만 허용하려면 `/상점관리 등록 1 판매 0 100 50`입니다. 기존 고정 가격표(`cropPrices`)는 더 이상 사용하지 않습니다.

첫 실행 후 `config/donationserver.cfg`에서 튜토리얼 안내 문구, 이동 쿨다운, 기부 목표와 칭호 구간을 설정합니다. 튜토리얼은 일반 서버 스폰에서 채팅으로만 나타나며 별도 이동이나 주민 이미지는 없습니다. 마지막 페이지에서 완료를 누르면 안내가 종료되고, 중간 페이지는 재접속 후 이어서 볼 수 있습니다.

영지는 첫 청크부터 `[영지 구매권]` 1장이 필요합니다. 첫 구매권은 튜토리얼 완료 시 지급하며, 추가 구매권은 NPC 상점에서 살 수 있습니다. 추가 청크는 같은 차원에서 기존 영지와 변이 맞닿아야 합니다. 구매권을 든 채 현재 청크에서 우클릭하거나, 인벤토리에 구매권을 넣고 `/영지설정`을 입력하면 됩니다. 일반 종이를 모루에서 같은 이름으로 바꿔도 구매권으로 인식되지 않습니다. 구매권은 종이 아이템이며 설명에 `영지를 구매할 수 있습니다.`가 표시됩니다. `/영지관리 최대 0`은 무제한(기본값)입니다. 신뢰 유저는 소유자의 모든 영지 청크에서 블록 설치·파괴, 상자/문과 엔티티 상호작용을 할 수 있습니다. 신뢰 목록은 UUID로 저장되어 닉네임이 바뀌어도 유지됩니다. 접속하지 않은 유저는 목록에 표시되는 UUID로 삭제할 수 있습니다. 폭발에 의한 영지 블록 피해도 차단합니다. 다른 모드가 이벤트 없이 직접 블록을 변경하는 자동화 동작은 별도 호환 확인이 필요합니다.

## 빌드

Java 8 JDK에서 `gradlew.bat build`를 실행합니다. 결과물은 `build/libs/donationserver-0.2.11.jar`입니다.
