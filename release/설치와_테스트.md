# Forge 1.12.2 코어 모드 0.2.12 — 최대 판매가 설정

NPC 상점 상품마다 변동 **판매가**의 상한을 지정할 수 있습니다. 구매가는 고정이며 상한의 영향을 받지 않습니다. 기존 월드와 상품 데이터는 유지됩니다. 이전 버전 상품의 최대 판매가는 기본적으로 `제한없음`입니다.

## 설치

1. 서버를 `stop`으로 종료하고 월드 폴더를 백업합니다.
2. 서버와 접속 PC의 `mods` 폴더에서 이전 `donationserver-*.jar`를 **mods 밖**으로 옮깁니다.
3. 양쪽에 `donationserver-0.2.12.jar`를 넣고 다시 실행합니다. 같은 버전이 하나씩만 있어야 합니다.

## 관리자 명령어

- 신규 상품: 주 손에 아이템을 들고 `/상점관리 등록 <상점ID> <구매|판매|둘다> <구매가> <판매가> <최저판매가> [최대판매가]`
- 기존 상품: `/상점관리 최대가 <상점ID> <상품번호> <최대판매가>`
- 상품 번호와 현재 범위: `/상점관리 상품 <상점ID>`
- 시세 변경 시험: `/상점관리 시세갱신`

예: `/상점관리 등록 1 둘다 200 100 50 150`은 구매가 200원, 판매 시작가 100원, 최저 50원, 최대 150원입니다. 이미 등록된 2번 상품은 `/상점관리 최대가 1 2 150`으로 바꿉니다. `0`으로 설정하면 최대 제한을 해제합니다. 최대가는 최저가보다 작게 설정할 수 없습니다. 기존 상품을 최대가 없이 재등록하면 기존 상한을 보존합니다.

## 확인

1. `/상점관리 상품 1`에서 설정한 최대가를 확인합니다.
2. `/상점관리 시세갱신`을 여러 번 실행한 후 판매가가 최대가를 넘지 않는지 확인합니다.
3. 최대가를 현재가보다 낮추면 현재가가 즉시 낮아지는지 확인합니다.

Java 8 / Forge 1.12.2 대상 빌드는 성공했습니다. 실제 멀티플레이 접속 테스트는 아직 진행하지 않았습니다.
