# Forge 1.12.2 코어 모드 0.2.11 — NPC 플레이어 스킨 수정

`/상점관리 스킨 <상점ID> <닉네임>` 실행 시 닉네임과 UUID만 저장하던 문제를 수정했습니다. 이제 Mojang 프로필에서 서명된 `textures` 값을 받아 NPC에 저장하고 모든 클라이언트에 동기화합니다. 커스텀 스킨이 있는 정품 Java Edition 계정이라면 해당 스킨이 표시되어야 합니다.

## 설치

1. 서버를 `stop`으로 종료합니다.
2. 실제 서버 PC와 모든 접속 PC의 `mods`에서 기존 `donationserver-*.jar`를 밖으로 옮기고 `donationserver-0.2.11.jar`만 넣습니다.
3. 서버와 게임을 다시 실행합니다.
4. 기존 NPC에는 이전 버전의 텍스처 데이터가 없으므로 `/상점관리 스킨 <상점ID> <닉네임>`을 다시 실행합니다.

## 테스트

1. NameMC가 아니라 **현재 정품 Java Edition 계정에서 사용 중인 정확한 닉네임**을 입력합니다.
2. 명령 성공 메시지가 나온 뒤 NPC를 다시 확인합니다.
3. `커스텀 스킨 정보를 받지 못했습니다`가 나오면 서버 인터넷 연결, Mojang 세션 서버 접근, 해당 계정의 커스텀 스킨 존재 여부를 확인합니다.

서버와 클라이언트의 코어 모드 버전이 반드시 같아야 합니다. 빌드 검증은 했지만 실제 Mojang 계정으로 접속한 화면 테스트는 운영자 PC에서 확인이 필요합니다.
