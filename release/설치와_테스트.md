# Forge 1.12.2 코어 모드 0.2.13

이번 버전은 일반 주민 거래를 차단하고 NPC 상점 판매 시세의 최대가 적용을 강화합니다.

## 변경 사항

- 일반 마인크래프트 주민을 우클릭해도 거래 화면이 열리지 않습니다.
- 판매 상품은 최대판매가를 반드시 설정해야 합니다.
- 30분 시세는 연속 상승할 수 있지만 설정된 최대가를 절대 넘지 않습니다.
- 최대가에 도달한 상품은 다음 갱신에서 고정 또는 하락합니다.
- 5회 연속 하락한 상품은 다음 갱신에서 상승합니다.
- 예전 데이터에 최대가가 없으면 현재가·기준가 중 높은 값을 최대가로 자동 지정합니다.

## 설치

1. 서버를 `stop`으로 종료하고 월드 폴더를 백업합니다.
2. 서버 `mods`에서 이전 `donationserver-*.jar`를 폴더 밖으로 옮깁니다.
3. `donationserver-0.2.13.jar`를 넣고 서버를 다시 실행합니다.
4. 런처 0.2.5 사용자는 게임 시작 시 같은 버전을 자동으로 내려받습니다.

## 관리자 명령 및 확인

- 신규 판매 상품: `/상점관리 등록 <상점ID> <구매|판매|둘다> <구매가> <판매가> <최저판매가> <최대판매가>`
- 기존 상품 최대가: `/상점관리 최대가 <상점ID> <상품번호> <최대판매가>`
- 값 확인: `/상점관리 상품 <상점ID>`
- 즉시 갱신 시험: `/상점관리 시세갱신`

예: `/상점관리 등록 1 둘다 200 100 50 150`. 최고가 적용은 `/상점관리 시세갱신`을 여러 번 실행하여 현재 판매가가 150원을 넘지 않는지 확인합니다.

Java 8 / Forge 1.12.2 빌드는 성공했습니다. 실제 멀티플레이 접속 화면 테스트는 운영 서버에서 확인해야 합니다.
