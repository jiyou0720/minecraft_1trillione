# Forge 1.12.2 코어 모드 0.2.14

## 변경 사항

- 개인 영지와 관리자 지정 상점가에서 적대 몬스터 생성을 차단합니다.
- 자연 생성, 스포너, 명령어, 다른 모드가 추가하는 적대 몬스터를 엔티티 진입 단계에서도 차단합니다.
- 이미 보호 구역에 들어온 적대 몬스터는 최대 1초 안에 제거합니다.
- 런처 서버 주소를 `112.166.104.209:25565`로 설정했습니다.
- 클라이언트 필수 모드에 공식 `CustomNPCs_1.12.2-(05Jul20).jar`를 추가했습니다.

## 서버 설치

1. 서버를 `stop`으로 종료하고 월드 폴더를 백업합니다.
2. 서버 `mods`에서 이전 `donationserver-*.jar`를 폴더 밖으로 옮깁니다.
3. `donationserver-0.2.14.jar`를 넣고 서버를 다시 실행합니다.
4. 서버와 클라이언트의 CustomNPCs 빌드가 `CustomNPCs_1.12.2-(05Jul20).jar`로 같은지 확인합니다.

기존 런처 0.2.5 사용자는 재설치할 필요가 없습니다. 런처를 완전히 종료한 뒤 다시 실행하면 GitHub 배포 목록에서 변경된 파일만 자동으로 내려받습니다.

## 확인

- 접속 오류 `CustomNPCs: Requires version 1.12 but mod is not found on client`가 사라져야 합니다.
- 영지와 상점가 안에서 적대 몬스터가 생성되거나 남아 있지 않아야 합니다.
- 동물과 상점 NPC는 영향을 받지 않아야 합니다.
