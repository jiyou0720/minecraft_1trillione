# 1억 기부 서버 전체 명령어 — 코어 모드 0.2.10

Minecraft 1.12.2 / Forge 14.23.5.2864 기준입니다. `<...>`는 입력할 값을 뜻하며 그대로 입력하지 않습니다. **일반 유저 표의 명령은 OP 없이 사용 가능**하고, 관리자 표의 명령만 OP가 필요합니다. OP 명령은 게임 안에서 관리자 권한으로 쓰는 것을 권장합니다. 현재 위치나 주 손 아이템을 참조하는 명령은 서버 콘솔에서 실행할 수 없습니다.

## 일반 유저

| 명령어 | 기능 |
| --- | --- |
| `/튜토리얼` | 현재 채팅 안내 페이지 다시 표시 |
| `/튜토리얼 다음` · `/튜토리얼 이전` | 안내 페이지 이동 |
| `/튜토리얼 다시` | 안내를 처음부터 다시 표시. 보상 재지급은 안 됨 |
| `/튜토리얼완료` | 안내 종료·최초 1회 보상 지급 |
| `/기부 <금액>` | 서버 목표에 돈 기부. 예: `/기부 5000` |
| `/기부현황` | 전체·내 기부액 및 잔액 확인 |
| `/송금 <접속 중인 닉네임> <금액>` | 다른 유저에게 돈 보내기. 예: `/송금 Alex 1000` |
| `/홈설정` | 현재 위치를 집으로 설정 |
| `/거점이동` | Shift+F와 같은 이동 메뉴 열기 |
| `/판매상점` | NPC 상점 이용 안내. 실제 거래는 NPC 우클릭 |
| `/영지설정` | 구매권 1장을 사용해 현재 청크 등록. 첫 청크도 구매권 필수 |
| `/영지설정 해제` | 현재 청크의 본인 영지만 해제. 구매권 환급 없음 |
| `/영지설정 정보` | 현재 청크 소유 상태와 내 보유 청크 수 |
| `/영지설정 표시` | 주변 내 영지의 바깥 경계를 약 8초간 파티클로 표시 |
| `/영지설정 유저추가 <접속 중인 닉네임>` | 내 영지 사용 허용 |
| `/영지설정 유저삭제 <닉네임 또는 UUID>` | 허용 취소. 오프라인 유저는 목록의 UUID 사용 |
| `/영지설정 유저목록` | 허용 유저 목록 확인 |

영지 구매권은 튜토리얼 완료 시 1장 지급되며 상점에서도 구매할 수 있는 전용 종이입니다. 모루로 같은 이름을 붙인 일반 종이는 인정되지 않습니다. 첫 청크 이후에는 보유 청크와 같은 차원에서 **변을 맞댄 청크**만 등록할 수 있습니다. 구매권을 들고 해당 청크에서 우클릭해도 등록됩니다.

## 관리자(OP): 돈·접속·영지·상점가

| 명령어 | 기능 |
| --- | --- |
| `/경제관리 돈추가 <접속 중인 닉네임> <금액>` | 잔액에 돈 추가 |
| `/경제관리 돈설정 <접속 중인 닉네임> <금액>` | 잔액을 해당 금액으로 설정 |
| `/경제관리 거래소설정` | 현재 위치를 거점 이동의 상점가 목적지로 설정 |
| `/유저접속장소설정` 또는 `/유저접속장소설정 현재` | 현재 위치를 신규 유저 시작 위치로 설정 |
| `/유저접속장소설정 기본` | 오버월드 X=0, Z=0의 지표면으로 되돌리기. Y=0이 아님 |
| `/유저접속장소설정 정보` | 현재 시작 위치 확인 |
| `/영지관리 최대 <청크 수>` | 1인 최대 보유량. `0`이면 무제한 |
| `/영지관리 현황` | 전체 영지 현황 확인 |
| `/상점가설정 <반경>` | 현재 위치 중심으로 반경 1~256블록 보호. 예: `/상점가설정 32` |
| `/상점가설정 정보` · `/상점가설정 해제` | 보호 구역 확인·해제 |

상점가 보호는 **OP를 포함한 모든 유저**의 블록 설치·파괴, 몬스터 생성·체류, 폭발로 인한 블록 파괴를 막습니다. 상점가를 수정하려면 `/상점가설정 해제` 후 작업하고 다시 설정하세요. `/상점관리 위치설정`(기존 `/경제관리 거래소설정`과 동일)은 워프 목적지이고 `/상점가설정`은 보호 구역이므로 **둘 다 따로 설정**해야 합니다.

## 관리자(OP): NPC 상점 설정 — 전체 명령어

| 명령어 | 기능 |
| --- | --- |
| `/상점관리 위치설정` | 현재 위치를 거점 이동 메뉴의 상점가 목적지로 지정 |
| `/상점관리 생성 <NPC 이름>` | 현재 위치에 플레이어형 NPC 상점을 만들고 상점 ID 출력. 예: `/상점관리 생성 농작물상점` |
| `/상점관리 목록` | 상점 ID 목록 |
| `/상점관리 상품 <상점ID>` | 해당 상점의 상품 번호·현재가·최저가·최대가 확인 |
| `/상점관리 등록 <상점ID> <구매\|판매\|둘다> <구매가> <판매가> <최저판매가> <최대판매가>` | **주 손 아이템**을 상품으로 등록·수정. 판매 상품은 최대판매가 필수 |
| `/상점관리 최대가 <상점ID> <상품번호> <최대판매가>` | 기존 판매 상품의 최대 판매가 변경 |
| `/상점관리 구매권등록 <상점ID> <가격>` | 해당 상점에 전용 영지 구매권을 구매 상품으로 등록·가격 수정 |
| `/상점관리 스킨 <상점ID> <Minecraft 닉네임>` | NPC에 그 계정의 플레이어 스킨 적용 |
| `/상점관리 시세` | 다음 판매 시세 갱신까지 남은 시간 확인 |
| `/상점관리 시세갱신` | 판매 시세 즉시 갱신 테스트·전체 공지 |
| `/상점관리 삭제상품 <상점ID> <상품번호>` | 상품 하나 삭제 |
| `/상점관리 삭제 <상점ID>` | NPC와 해당 상점의 모든 등록 상품 삭제 |

`구매`는 **유저가 상점에서 구매**, `판매`는 **유저가 상점에 판매**한다는 뜻입니다. 활성화하지 않은 방향의 가격은 `0`을 넣습니다. 판매 상품의 판매가·최저가·최대가는 1원 이상이어야 하고 `최저가 ≤ 최초 판매가 ≤ 최대가`여야 합니다. 구매가는 고정이고 판매가만 30분마다 ±10% 변동합니다. 연속 상승은 가능하지만 최대가를 절대 넘지 않으며, 최대가에서는 고정 또는 하락합니다. 5회 연속 하락하면 다음 변경은 상승합니다.

예시: 사과를 주 손에 들고 `/상점관리 등록 1 둘다 200 100 50 150` → 유저 구매 200원, 유저 판매 초기 100원, 판매 최저 50원·최대 150원. 기존 상품 #2의 상한을 300원으로 바꾸려면 `/상점관리 최대가 1 2 300`. 판매만 하려면 `/상점관리 등록 1 판매 0 100 50 150`. 영지 구매권은 `/상점관리 구매권등록 1 5000`.

상점 NPC를 우클릭해 아이콘을 고른 뒤 `1개`·`10개`·`64개`와 구매/판매 버튼을 사용합니다. 거래는 NPC로부터 6블록 이내에서만 가능합니다.

## 관리자(OP): 스킨 랜덤박스

| 명령어 | 기능 |
| --- | --- |
| `/스킨박스관리 생성 <이름>` | 랜덤박스 종류 생성, ID 출력 |
| `/스킨박스관리 목록` | 등록된 박스 ID 목록 |
| `/스킨박스관리 보상추가 <박스ID> <가중치>` | **주 손 아이템**을 보상으로 등록. 가중치가 클수록 당첨 확률 증가 |
| `/스킨박스관리 보상목록 <박스ID>` | 보상 번호·가중치 확인 |
| `/스킨박스관리 보상삭제 <박스ID> <보상번호>` | 보상 삭제 |
| `/스킨박스관리 받기 <박스ID>` | 해당 박스 아이템 1개 받기 |

예시: `/스킨박스관리 생성 기본박스` → 스킨 아이템을 주 손에 들고 `/스킨박스관리 보상추가 1 10` → `/스킨박스관리 받기 1`. 받은 박스 아이템을 주 손에 들고 `/상점관리 등록 1 구매 5000 0 0`으로 상점에 팔 수 있습니다.

## 단축키·서버 운영

- **Shift+F**: 워프 아이콘 메뉴. 아이콘에 마우스를 올려 목적지 설명 보기. Ctrl+F가 아닙니다.
- 서버 콘솔: `op <닉네임>`으로 관리자 지정, `stop`으로 안전하게 종료. 콘솔 명령에는 `/`를 쓰지 않습니다.
- `server`와 `server_새월드`는 같은 25565 포트를 사용하므로 둘 중 하나만 켜세요.
- Aquaculture·GokiStats·Joy of Painting 명령어는 이 코어 모드의 명령어가 아니며, 각 모드 자체 설명서를 확인해야 합니다. ArtMap은 현재 서버에 설치되지 않았습니다.
